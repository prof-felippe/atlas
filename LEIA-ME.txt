ATLAS DO PROF. FELIPPE — pacote pronto para publicar
====================================================

Todos os arquivos ficam na MESMA pasta (não há subpastas):

index.html                página principal (catálogo, jogos rápidos e aulas)
climograma.html           Climograma Quiz (fotos já embutidas no arquivo)
piramides.html            Que país é este? (pirâmides etárias)
linhas-na-floresta.html   Linhas na Floresta (livro-jogo, funciona offline)
linhas-capa.png           capa usada na vitrine
CREDITOS-DAS-FOTOS.txt    créditos das fotos do Climograma (Wikimedia Commons)
.nojekyll                 arquivo vazio para o GitHub Pages (opcional)

IMPORTANTE: envie todos juntos, lado a lado. A página principal abre os
jogos pelo nome do arquivo e cada jogo volta para "index.html".
Não renomeie os arquivos.


PUBLICAR PELO GITHUB PAGES
--------------------------
1. Em https://github.com clique em "+ > New repository".
   Nome: atlas-geografia · marque Public · "Create repository".
2. Clique em "uploading an existing file".
3. Selecione TODOS os arquivos desta pasta (Ctrl+A) e arraste para a
   página (ou use "choose your files" e selecione todos).
4. Clique em "Commit changes".
5. Settings > Pages > Source: "Deploy from a branch" > main > / (root) > Save.
6. Em 1–2 minutos: https://SEU-USUARIO.github.io/atlas-geografia/

Para conferir: na página inicial do repositório, o index.html e os
jogos devem aparecer listados lado a lado (nenhum dentro de outra pasta).

Para atualizar: "Add file > Upload files" e envie os arquivos novos com
o mesmo nome; o GitHub substitui os antigos.


PUBLICAR PELO NETLIFY DROP
--------------------------
Acesse https://app.netlify.com/drop e arraste esta pasta inteira.
